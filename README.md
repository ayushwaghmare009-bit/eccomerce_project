# 🛒 MyMarketplace - Django E-Commerce Web Application

A full-featured, secure e-commerce web marketplace built using **Python**, **Django**, and **Bootstrap 5**. This project implements a complete shopping workflow from product discovery and session-based cart management to user authentication and protected order processing.

---

## 🚀 Key Features

* **Dynamic Product Catalog & Categories**: Browse products seamlessly filtered by categories with detailed view pages.
* **Session-Based Shopping Cart**: Add, update, and manage items dynamically using persistent session storage.
* **User Authentication**: Secure user registration, login, and logout workflows powered by Django's built-in auth system.
* **Protected Checkout System**: `@login_required` routing ensuring users must sign in before entering sensitive shipping and payment details.
* **Order Persistence**: Automatically records orders and relational order items in the database upon successful checkout.
* **Modern UI & Design**: Fully responsive frontend built with Bootstrap 5, custom color gradients, and icons.

---

## 🛠️ Tech Stack

* **Backend**: Python, Django 5.x
* **Frontend**: HTML5, CSS3, Bootstrap 5, Bootstrap Icons
* **Database**: SQLite
* **Version Control**: Git & GitHub
